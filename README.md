# Raj Patel Portfolio

A responsive, dark-gradient portfolio based on the supplied reference screenshot and portrait images.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. No build step is required.
3. For best local testing, use VS Code with the Live Server extension.

## Customize before publishing
- Check that your name, degree, location, and profile photo are correct.
- Edit `index.html` to add your actual education, email, LinkedIn, resume PDF, and other project links.
- Review the Skills section. Remove any language or technology you have not used or cannot explain confidently.
- The featured sign-language project link is the exact repository supplied by the user. Check the repository's README and update the description/technology tags to match the implementation.
- Replace the illustrative sign-language graphic with a real screenshot or demo image when available.
- Add more project cards only when you have real repositories and working demos.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive design, colors, layout, and animations
- `script.js` — mobile menu, current year, and copy-profile button
- `assets/` — supplied portrait image(s)

## Publish
Upload the extracted project to a GitHub repository, then import it into Vercel or use any static hosting provider. This site is plain HTML/CSS/JS, so no framework installation is required.
